# Стикеры

Виртуальные стикеры для задач, которых нет в git: чек-листы на цветных
карточках, которые лежат на рабочем столе. Оформление следует Apple HIG:
системные шрифты, пастельная палитра iOS, скругления, круглые отметки как в
«Напоминаниях», крупные зоны нажатия.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Возможности

Каждый стикер — отдельное окно со своим заголовком, списком задач, цветом,
тегом и сроком. Срок подсвечивается: оранжевым в день дедлайна, красной датой после
него. Булавка в шапке закрепляет стикер поверх всех окон, кнопки шапки меняют цвет, сворачивают, скрывают и удаляют стикер.
Тег и срок меняются внизу карточки; корзина внизу убирает выполненные задачи.

| Действие | Как |
|---|---|
| Новый стикер | `+` в шапке, `Ctrl+N` или значок в трее |
| Переместить | потянуть за верхнюю полосу |
| Изменить размер | угол в правом нижнем углу |
| Удалить задачу | крестик при наведении на строку, либо стереть текст |
| Выйти | `Ctrl+Q` (`Cmd+Q` на macOS) или трей |

## Где лежат данные

Файл `notes.json` в системной папке данных приложения (Qt `AppDataLocation`,
каталог `VirtualStickies`). Запись атомарная, формат — обычный JSON, так что
его легко бэкапить или положить под git.

## Структура

```
main.py              точка входа
stickies/model.py    Note/Task и хранение в JSON
stickies/theme.py    палитра и цвета iOS
stickies/widgets.py  круглая отметка, кнопки-иконки, строка задачи
stickies/sticky.py   окно стикера
stickies/app.py      менеджер стикеров, трей, запуск
```

## Новое управление

- Длинные заголовки и задачи переносятся по ширине карточки. `Enter` внутри задачи добавляет строку; поле «Новая задача» создаёт следующую задачу.
- Кнопка с тремя линиями справа от задачи открывает/скрывает её многострочное описание. Скрытие описания сохраняет текст. Крестик рядом удаляет задачу.
- В шапке: палитра — цвет, стрелка вверх — свернуть до шапки, стрелка вниз — развернуть, корзина — удалить стикер с подтверждением, `×` — скрыть в трей. Если трей недоступен, окно минимизируется.
- Свёрнутый стикер сохраняет заголовок и управление; он уменьшается до 260 × 104 пикселей; его состояние и развёрнутые ширина и высота восстанавливаются при следующем запуске.
- Размер меняется за нижний левый или правый угол. Открытие, скрытие и сворачивание анимированы.
- В меню трея → «Стикеры» можно открыть конкретную карточку по заголовку. Двойной щелчок по трею показывает все стикеры.
- Старые `notes.json` совместимы: описания и состояние сворачивания добавляются при сохранении. Папка `VirtualStickies` сохранена, переносить данные не нужно.

## Windows 10/11: exe и автозапуск

Сборка выполняется **на Windows**, установленный Python у пользователя готового `.exe` не нужен.

1. Загрузите изменения в GitHub, откройте **Actions → Windows executable → Run workflow**.
2. После успешного выполнения скачайте артефакт **TODOes-Windows**, распакуйте `TODOes.exe` в постоянную папку и запустите.
3. В меню трея включите **«Запускать с Windows (в трей)»**. Это запись для текущего пользователя; права администратора не нужны. Удаление галочки отключает автозапуск.

Если перемещаете `.exe`, выключите автозапуск до перемещения и включите снова из нового расположения. `TODOes.exe --tray` запускает приложение без показа карточек при наличии трея. Без доступного трея карточки показываются, чтобы приложение оставалось доступным.

Для локальной сборки на Windows с Python 3.12:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
.\scripts\build_windows.ps1
```

Результат: `dist/TODOes.exe`. Сборка также запускается для тегов `v*`. Исполняемый файл не подписан: Windows может показать предупреждение SmartScreen. Логотип хранится в `assets/todoes.svg`, ICO генерируется скриптом сборки.

## Проверки

```bash
python -m unittest discover -s tests -v
```

В Linux без дисплея задайте `QT_QPA_PLATFORM=offscreen`. Тесты проверяют перенос текста, описания, совместимость JSON, сворачивание, анимации и выбор стикера из меню. Внешний вид, системный трей, реальный автозапуск и готовый `.exe` дополнительно проверяются на Windows.

## Отложенные идеи

По согласованию не включены: синхронизация через Git, вытягивание из бесконечной пачки вместо `+`, свободное размещение текста и полное скрытие окон с панели задач. Общие пункты «Добавить фишки» и «Перекопать код» реализованы через конкретные изменения выше, а не отдельные несогласованные функции.
